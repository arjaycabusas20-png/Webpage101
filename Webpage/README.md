# Lumen — Front Page

This repository contains a single-file front-page design `Index.html` made for a class activity. Follow the instructions below to publish and share the page from your GitHub account.

Quick steps (recommended):

1. Initialize local Git and commit:

```bash
git init
git add Index.html
git commit -m "Add Lumen front-page design"
```

2. Create a GitHub repository and push (using GitHub CLI `gh`):

```bash
gh repo create YOUR_USERNAME/lumen-frontpage --public --source=. --remote=origin --push
```

If you don't have `gh`, create a repository on GitHub.com and then:

```bash
git remote add origin https://github.com/YOUR_USERNAME/REPO_NAME.git
git branch -M main
git push -u origin main
```

3. Publish with GitHub Pages (optional):

- On GitHub, go to Settings → Pages and select the `main` branch and `/ (root)` folder, then save. The site URL will be shown there.

4. Share the link in MS Teams:

- Copy the repository or GitHub Pages URL and paste the link in your MS Teams message. Only the link is required.

Notes:
- Replace `YOUR_USERNAME` and `REPO_NAME` with your GitHub account and chosen repo name.
- If you want me to run commands or create a repo for you, I can provide step-by-step help (you need to authenticate `gh`).
